# Future Features — Do Not Implement in the MVP

Consider these only after the core client is stable:

- Threads and threaded replies.
- Reactions.
- Attachments and file uploads.
- Rich text formatting.
- Mentions and autocomplete.
- Notifications.
- Background polling.
- Multiple Google accounts.
- Conversation pinning and custom ordering.
- Full-text search with SQLite FTS5.
- Configurable themes.
- Vim-style command mode.
- Offline draft persistence.
- Message editing and deletion, if supported by the API.
- Accessibility improvements for screen readers.
